# RAG 中台学习与交接文档

本目录面向学习现有项目的开发者和后续接手的 AI。项目已有完整的一期源码，学习从理解、运行、验证和独立复刻出发，不再按空项目重新选技术栈。

## 阅读入口

1. [交接与学习启动手册](交接文档及学习路线/RAG中台_交接与学习启动手册.md)：先确认项目是什么、技术栈与源码在哪里、请求怎样运行、测试证明了什么。
2. [学习路线总纲](交接文档及学习路线/RAG中台_学习路线总纲.md)：12 个知识主题拆成 3 阶段、20 个核心学习日，默认每天 2–3 小时，约 4 周。
3. [第一阶段 Day01 教材](学习单元/第一阶段/RAG中台_Day01_项目边界工程入口与契约验证.md)：从项目边界、启动入口和接口契约开始，附可运行实验与失败复现。
4. [技术栈和源码基线](交接文档及学习路线/基线核对记录_2026-10-25.json)：首次交接时从锁文件与源码提取的快照，供后续核对；当前学习进度以总纲为准。

当前已交付 Day01 完整教材、实验、[学习记录模板](学习单元/第一阶段/Day01_学习记录模板.md)和[验收记录](学习单元/第一阶段/Day01_实验/验收记录.json)。Day02–20 教材按后续学习任务逐份制作；用户学习状态尚未代填。
